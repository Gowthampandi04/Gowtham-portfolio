# Gowthampandi K - Portfolio

Animated 3D portfolio built with HTML, CSS, JavaScript and Three.js.

## Run locally
1. Open the folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html` and choose **Open with Live Server**.
(Or just double-click `index.html`. An internet connection is needed for fonts, icons and Three.js.)

## Structure
```
index.html
autoCV.pdf
css/style.css
js/main.js
images/profile.jpg
```

## Deploy (GitHub Pages)
Push to GitHub, then Settings > Pages > Deploy from branch > `main` / root.

## To customise
- Project links: edit the `href` values in the Projects section of `index.html`.
- Contact email: search for `gowthambaby0304@gmail.com` in `index.html` and `js/main.js`.
